# Tiktok App Policies 

Two documents, both required by the TikTok Developer Portal before app review.

1. valnet-tiktok-privacy-policy.md
What data the pipeline pulls from TikTok, why, where it's stored, and how it's deleted. Covers Display API + Business API, metrics only (no monetization), Valnet-owned accounts only. Adapted from the existing Meta policy, same 10-section structure.

2. valnet-tiktok-terms-of-service.md
Rules of use for the app. States it's internal-only with no public login, lists prohibited uses, and defers to TikTok's developer terms where they conflict. 15 sections.
